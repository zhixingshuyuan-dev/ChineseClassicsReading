1. Selamlaşma ve İnsanlar (问候与人际)
1
Merhaba你好【词类】感叹词 / 问候语
【语法细节】无变位，用于任意场合（正式/非正式）。是最通用的打招呼方式。复数敬称可使用"Merhaba efendim"（先生/女士您好）。【词源】来自阿拉伯语 "merhabā" (مرحباً)，原意为"欢迎/宽阔之地"。经奥斯曼土耳其语进入现代土耳其语。阿拉伯语词根 R-H-B 意为"广阔/欢迎"。 ,，【词类】标点符号
【语法细节】土耳其语中逗号用于分隔短语或表示停顿。【词源】标点符号系统源自欧洲，奥斯曼时期开始使用。 nasılsınız您怎么样【词类】疑问词 + 动词人称后缀
【语法细节】nasıl(如何/怎样) + 第二人称复数现在时后缀"-sınız"，构成"您(们)如何"。正式场合用复数敬称，朋友之间用"nasılsın"（你怎样）。【词源】"nasıl"源自古突厥语"nasıl"，由"ne asıl"（什么本质）合并而来。"-sınız"是古突厥语动词人称标记的遗留，与蒙古语人称后缀同源。 ?？【词类】标点符号
【语法细节】土耳其语疑问句需加问号，口语中通过语调区分。【词源】问号源自拉丁语"quaestio"缩写，16世纪开始使用。
你好，您好吗？

Benim我的【词类】人称代词 + 所有格后缀
【语法细节】ben(我) + -im(所有格后缀)，表示"我的"。土耳其语所有格后缀遵循元音和谐规则：ben-im, sen-in, on-un, biz-im, siz-in, onlar-ın。【词源】"ben"源自古突厥语"ben"，与蒙古语"би"、满语"bi"同源，属于阿尔泰语系共有词汇。原始突厥语形式为*ben。 adım名字【词类】名词 + 第一人称所有格
【语法细节】ad(名字/名称) + -ım(我的)，构成"我的名字"。土耳其语中表达"我的XX"时，直接将所有格后缀加在名词后，不需要像英语那样使用单独的物主代词。【词源】"ad"源自古突厥语"āt"（名字/名声/称号）。同时代古突厥文碑铭中出现"𐰀𐱃"形式。与蒙古语"алд"（名声）同源。 Ali阿里【词类】专有名词 / 男性名字
【语法细节】来自阿拉伯语的常见人名。在土耳其语中无需变格。属格形式为"Ali'nin"（阿里的），与格"Ali'ye"（给阿里）。【词源】来自阿拉伯语"علي" (ʿAlī)，意为"崇高的、卓越的"。伊斯兰教第四任哈里发阿里·本·阿比·塔利卜之名，什叶派第一位伊玛目。 .。【词类】标点符号
【语法细节】土耳其语句号表示陈述句结束。【词源】句号最早出现在古希腊手稿中。
我的名字是阿里。
3
Tanıştığımıza到我们认识(这件事)【词类】动词名化形式 + 向格后缀
【语法细节】tanış-（认识） + -tığı (名化后缀) + -mız (第一人称复数所有格) + -a (向格后缀)，字面意思"到我们认识(这件事)"。这是土耳其语表达"很高兴认识你"的固定句型"Tanıştığımıza memnun oldum"。【词源】"tanış-"源自古突厥语"tanu-"（知道/认出/认识）。加相互后缀"-ış"构成"tanışmak"（互相认识）。与蒙古语"таних"（认识）同源。 memnun高兴的/满意的【词类】形容词
【语法细节】用来表达"感到满意/高兴"的心情。常用在"memnun olmak"结构中，表示"变得高兴/感到满意"。'memnun oldum'是固定表达，意思是"我变得高兴了"。【词源】来自阿拉伯语"ممنون" (mamnūn)，原意为"受恩惠的、被感谢的"。阿拉伯语词根 M-N-N 意为"恩惠/赐予"。从"感受到恩惠"引申为"感到满意/高兴"。 oldum我变得/我成为了【词类】动词 确定过去时 第一人称单数
【语法细节】ol-（成为/发生） + -dum（第一人称单数确定过去时后缀）。表示"我成为了.../我...了"。'memnun oldum'一起构成固定搭配，意为"（我变得）很高兴"。【词源】"olmak"源自古突厥语"ol-"，意为"成为/发生"。是与"那"（ol）同源的动词。"ol-"同时用作助动词，是土耳其语最核心的动词之一。 .。【词类】标点符号
【语法细节】表示句子结束。
很高兴认识你。

Benim我的【词类】人称代词 + 所有格后缀
【语法细节】ben(我) + -im(所有格)。土耳其语中表达"拥有某物"的典型句型是"Benim X'im var" = "我有一个X"。"benim"有时可以省略，因为后缀已表明关系。【词源】参见前文"ben"词源。 bir一个【词类】数词 / 不定冠词
【语法细节】表示数量"一"，也作为不定冠词使用。土耳其语没有冠词系统，"bir"是唯一接近不定冠词功能的词。置于名词前。【词源】源自古突厥语"bīr"，与一切突厥语系语言中的"bir"同源。原始突厥语形式为*bīr。 ablam我的姐姐【词类】名词 + 第一人称所有格
【语法细节】abla(姐姐) + -m(我的)。土耳其语中家庭成员的称呼加上所有格后缀构成"我的XX"。【词源】"abla"是土耳其语特有的词汇，可能与婴儿语言有关（类似"aba"）。在日语中"あば"也有类似含义。现代土耳其语标准化的亲属称谓。 var有/存在【词类】存在动词
【语法细节】表示"存在/拥有"。与英语的"there is/are"类似。句型结构为"所有者(位格) + 物品 + var/yok"。此处使用"benim ... ablam var"结构表示"我有姐姐"。【词源】源自古突厥语"bar"（存在）。与蒙古语"байх"（有/存在）同源。其否定形式"yok"（没有）同样源自古突厥语"yok"。 .。
我有一个姐姐。

Annem我的妈妈【词类】名词 + 第一人称所有格
【语法细节】anne(母亲/妈妈) + -m(我的)。注意：anne以元音-e结尾，直接加-m。土耳其语中母亲另一个称呼是"anne"，更口语化的还有"ana"。【词源】"anne"源自古突厥语"ana/eŋe"，与蒙古语"эх"（母亲）同源。是阿尔泰语系基础的亲属词汇。"ana"形式在许多突厥语言中仍然使用。 her每个【词类】形容词
【语法细节】表示"每一个/所有的"。常与时间名词搭配，如"her gün"(每天)、"her sabah"(每天早晨)、"her gece"(每晚)。【词源】来自波斯语"هر" (har)。波斯语中意为"每个/任何"。奥斯曼时期随着波斯文学的影响进入土耳其语，成为日常用词。 sabah早晨【词类】名词 时间
【语法细节】表示早晨/早上。可以单独作时间状语(如"sabah geldi"=早上来了)，也可与介词搭配(如"sabahleyin"=在早上)。【词源】源自古突厥语"sub"（早晨/黎明）。与楚瓦什语"суп"（早上）同源，和蒙古语"сүбэр"（黎明）可能存在联系。 erken早地【词类】副词 / 形容词
【语法细节】既可以作形容词（erken tren = 早班火车），也可以作副词（erken kalkmak = 早起）。此处修饰kalkmak（起床），表示"早起"。【词源】源自古突厥语"erken"（早）。与"erkek"（男人/男性）共享词根"er-"（早/前），表示"在...之前"。蒙古语"эрт"（早）同源。 kalkar起床【词类】动词 一般现在时 第三人称单数
【语法细节】kalk-（起床/起来/起立） + -ar（一般现在时第三人称后缀）。表示习惯性动作"她/他起床"。【词源】"kalkmak"源自古突厥语"kalık-"（升起/起身/站立）。与"kalkınmak"（兴起/发展/振兴）同词根。蒙古语"калх"（升起）可能有关系。 .。
我妈妈每天早上早起。

Bir一【词类】数词
【语法细节】数量词"一"。点餐时光说"bir"不完整，需要搭配名词。【词源】源自古突厥语"bīr"。参见前文。 bardak杯【词类】名词
【语法细节】量词，表示"一杯"。与液体名词搭配。【词源】来自波斯语"باردك" (bârdak)。指陶制的杯子/容器。波斯语本身借自中古波斯语。 su水【词类】名词
【语法细节】基本词汇，不可数名词。水在土耳其文化中有重要地位，招待客人必奉水。【词源】源自古突厥语"sub"。原始突厥语中基本词汇，与蒙古语"ус"同源。几乎所有突厥语系语言中都是"su"或类似形式。 lütfen请【词类】礼貌词/感叹词
【语法细节】用于表达礼貌请求，常放在句尾。可以和动词搭配使用，如"Lütfen oturun"(请坐)。【词源】来自奥斯曼土耳其语"لطفاً"，源自阿拉伯语"لطفاً" (lutfan)，词根L-T-F意为"仁慈/善意"。字面意思是"仁慈地"。 .。
请给我一杯水。

Türk土耳其的【词类】专有名词 / 形容词
【语法细节】表示"土耳其/土耳其人的"。常用来修饰名词，如Türk kahvesi(土耳其咖啡)、Türk mutfağı(土耳其菜)。【词源】"Türk"源自古突厥语"türük"，首次出现在6世纪的古突厥文碑铭（如阙特勤碑）。原始含义可能是"力量/民族"。 kahvesini咖啡(宾格)【词类】名词 + 宾格后缀 + 第三人称所有格
【语法细节】kahve(咖啡) + -si(第三人称所有格) + -ni(宾格后缀)，构成"他的/她的/它的咖啡"，作动词"seviyorum"(喜欢)的宾语。【词源】"kahve"来自阿拉伯语"قهوة" (qahwa)。阿拉伯语原指一种提神饮料。经奥斯曼语进入欧洲语言（咖啡/coffee）。 çok很/非常/很多【词类】副词
【语法细节】表示程度"非常"或数量"很多"。此处修饰seviyorum，意为"非常喜欢"。【词源】源自古突厥语"çok"（多）。与蒙古语"цөөн"（少）可能反义关系。"çok"在现代土耳其语中兼作"非常"和"很多"。 seviyorum我喜欢/我爱【词类】动词 现在进行时 第一人称单数
【语法细节】sev-（爱/喜欢） + -iyor（现在进行时标记） + -um（第一人称）。土耳其语现在进行时可以表达当下正在进行的动作，也可以表达长期状态（喜欢/爱）。【词源】"sevmek"源自古突厥语"sev-"（爱/喜欢）。与蒙古语"сээх"（爱慕）同源。是阿尔泰语系基本情感词汇。动词变位极其规则。 .。
我非常喜欢土耳其咖啡。

Hesap账单【词类】名词
【语法细节】在餐厅或咖啡馆结束时使用。句型"Hesap alabilir miyim?"（我可以拿账单吗？）是结账的标准表达。【词源】来自阿拉伯语"حساب" (hisāb)。阿拉伯语词根H-S-B意为"计算/计数"。英语"account"也是通过拉丁语从同一闪米特词根派生。 alabilir可以拿【词类】动词 能力式 第三人称单数
【语法细节】al-（拿/取） + -abil-（能力标记） + -ir（第三人称现在时）。表示"他/她可以拿"。【词源】"almak"源自古突厥语"al-"（拿/取）。与蒙古语"авах"（拿）同源。能力式后缀"-abil-"是土耳其语语法中较新的发展，表示可能性。 miyim我...吗【词类】疑问助词 + 第一人称
【语法细节】mi(疑问词) + -yim(第一人称现在时)。构成问句"我可以...吗？"。疑问词需要与句末元音和谐：mi/mu/mü。【词源】疑问词"mi"源自古突厥语疑问标记"mU"。与蒙古语"уу"有同源关系。是突厥语系普遍存在的疑问标记。 ?？
我可以结账吗？

Bu这个【词类】指示形容词
【语法细节】表示'这个'，后面直接跟名词，如bu elma(这个苹果)。复数形式为"bunlar"(这些)。【词源】源自古突厥语"bu"。与蒙古语"ээ"（这）同源。形成基本的指示系统bu(这)-şu(那)-o(那个)。 elma苹果【词类】名词
【语法细节】基本名词。复数形式：elmalar.【词源】"elma"源自古突厥语"alma"。可能与"al"（红色）有关。是突厥语系共同词汇。 ne什么【词类】疑问代词
【语法细节】用于询问事物。【词源】源自古突厥语"ne"。与蒙古语"юу"（什么）形式不同但功能相同。中亚突厥语中都使用"ne"。 kadar多少/那么【词类】疑问词/后置词
【语法细节】"ne kadar"一起构成疑问短语"多少(钱)"。询问价格时使用。【词源】来自阿拉伯语"قدر" (qadar)，意为"数量/量度"。经波斯语传入土耳其语。 ?？
这个苹果多少钱？

【语法细节】dene-（试/尝） + -yebil-（能力标记） + -ir（第三人称）。表示"他/她可以试"。【词源】"denemek"来源于"den-"，与"dene-"（测试/尝试）同词根。可能与"dene"（实验）有关。 miyim我...吗【词类】疑问 + 第一人称
【语法细节】见前文。 ?？

Kredi信用/贷记【词类】名词

Otobüs公交车【词类】名词
【语法细节】城市公共交通车辆。复数otobüsler。【词源】来自法语"autobus"，由希腊语"αὐτός"(自己)+拉丁语"omnibus"(为了所有人)组成。 durağı车站【词类】名词 + 第三人称所有格
【语法细节】durak(站/停靠点) + -ı(第三人称所有格)。"otobüs durağı"意为"公交站"。【词源】"durak"由"dur-"（停）+"-ak"（地点后缀）构成。意为"停靠的地方"。 nerede哪里【词类】疑问词 位格
【语法细节】nere(哪里) + -de(位格后缀)。询问位置时使用。【词源】"nere"来自"ne"与"yer"(地方)的融合。"-de"是古突厥语位格后缀。 ?？
公交车站在哪里？

Havalimanına到机场【词类】名词 + 向格

我怎样才能去机场？

Sağa向右【词类】名词 + 向格
【语法细节】sağ(右边) + -a(向格后缀)，意为"向右边"。【词源】"sağ"源自古突厥语"sağ"（右）。与蒙古语"баруун"（右）不同源。 dönün请转(弯)【词类】动词 祈使式 第二人称复数

请向右转。
